# LingoStar 사용 안내

LingoStar는 여러 언어 학습 세션을 만들고 ChatGPT 안에서 이어서 연습할 수 있게 도와줍니다.

## 세션

- 목표 언어나 목표가 다르면 별도의 세션을 만들 수 있습니다.
- 섹션을 시작하기 전에 대시보드에서 어떤 세션을 사용할지 고르세요.
- 세션 삭제는 대시보드에서 한 번 더 확인한 뒤 실행됩니다.

## 섹션

- 한 섹션에는 언어 정보, 듣기, 읽기, 쓰기, 말하기 문제가 들어갑니다.
- 다음 섹션을 만들기 전에 현재 섹션을 끝내는 흐름을 권장합니다.
- 듣기나 말하기를 건너뛰면 현재 문제만 건너뛴 것으로 기록됩니다.

## 음성

- 듣기는 가능한 경우 브라우저 음성 기능을 사용합니다.
- 일부 모바일 ChatGPT 환경에서는 말하기가 제한될 수 있습니다. 이 경우 답안을 직접 입력하거나 현재 말하기 문제를 건너뛰세요.

## Ask AI

- Ask AI는 현재 문제에 대해 질문할 때 사용합니다.
- ChatGPT가 답하는 동안에도 현재 섹션과 작성 중인 답안은 위젯에 유지됩니다.

## 설정

- 영역별 문제 수, 통과 기준, 목표 완료에 필요한 섹션 수, 말하기 속도, 말하기 사용 여부를 조정할 수 있습니다.
