# LingoStar 도움말

LingoStar는 ChatGPT 안에서 언어 공부를 이어 가는 앱입니다. 앱 안에서는 다음 말로 안내합니다.

- 학습 트랙: 일본어 JLPT N4 준비처럼 언어와 목표를 묶은 공부 단위입니다.
- 연습 묶음: 한 번에 푸는 문제 세트입니다.
- 문제: 언어 정보, 듣기, 읽기, 쓰기, 말하기 중 하나입니다.

## 처음 시작하기

- "일본어 JLPT N4를 준비하고 싶어요"처럼 말하면 새 학습 트랙을 만들 수 있습니다.
- 이미 학습 트랙이 있으면 선택 화면에서 이어 할 트랙을 고를 수 있습니다.
- 진행 상황을 보고 싶으면 "제 언어별 학습 트랙을 보여 주세요"라고 말하세요.

## 대화로 설정 바꾸기

설정 화면은 따로 없습니다. ChatGPT 입력창에 자연스럽게 말하면 됩니다.

- "설정을 바꾸고 싶어요"
- "다음부터 말하기도 포함해 주세요"
- "말하기는 빼고 읽기와 쓰기를 더 많이 풀고 싶어요"
- "표시 언어를 영어로 바꿔 주세요"
- "듣기 속도를 조금 느리게 해 주세요"
- "일본어와 프랑스어를 각각 따로 공부하고 싶어요"

설정을 바꾸면 다음 연습 묶음을 만들 때 반영됩니다. 이미 열려 있는 연습 묶음은 안정적으로 끝낼 수 있도록 그대로 둡니다.

## 연습하기

- 문제는 화면에서 직접 풀고, 궁금한 점은 ChatGPT 입력창에 물어보세요.
- 화면 안에 별도 질문창은 없습니다. ChatGPT가 현재 문제 맥락을 알고 답합니다.
- 연습 묶음을 다 풀면 "다 풀었습니다" 흐름으로 채점과 저장이 진행됩니다.
- 모르는 문제는 현재 문제만 건너뛸 수 있습니다.

## 말하기와 듣기

- 듣기는 가능한 환경에서 바로 재생됩니다.
- 일부 모바일 ChatGPT 환경에서는 말하기 입력이 제한될 수 있습니다. 이 경우 화면 중앙에 안내가 나오며, 답을 직접 입력하거나 현재 말하기 문제만 건너뛸 수 있습니다.
- "다음부터 말하기를 포함해 주세요" 또는 "말하기는 빼 주세요"라고 말해 다음 연습 묶음 설정을 바꿀 수 있습니다.

## 학습 트랙 관리

- "제 언어별 학습 트랙을 보여 주세요"라고 하면 표로 현재 상태를 볼 수 있습니다.
- "일본어 트랙을 삭제해 주세요"처럼 특정 트랙을 삭제할 수 있습니다.
- "모든 언어 학습 트랙을 삭제해 주세요"라고 말하면 현재 사용자에게 속한 트랙만 삭제됩니다.
- 삭제 후에도 다른 사용자의 학습 트랙에는 접근하거나 영향을 줄 수 없습니다.

## 기본 명령

- "다음 연습 시작"
- "현재 문제를 설명해 주세요"
- "설정을 바꾸고 싶어요"
- "제 언어별 학습 트랙을 보여 주세요"
- "일본어 트랙을 삭제해 주세요"
