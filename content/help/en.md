# LingoStar Help

LingoStar helps you study languages inside ChatGPT. It uses these learner-facing terms:

- Learning track: one language and goal, such as Japanese for JLPT N4.
- Practice set: one group of exercises you solve in the widget.
- Exercise: one language info, listening, reading, writing, or speaking item.

## Getting Started

- Say something like "I want to prepare for JLPT N4 Japanese" to create a learning track.
- If you already have tracks, choose one from the track picker.
- Ask "Show my language learning tracks" to see your progress in a table.

## Conversational Settings

There is no separate settings screen. Change settings through the ChatGPT composer.

- "I want to change my settings"
- "Include speaking next time"
- "Skip speaking and give me more reading and writing"
- "Change the display language to Korean"
- "Make listening audio a little slower"
- "I want separate Japanese and French tracks"

Setting changes apply to the next practice set. The current practice set stays stable so you can finish it.

## Practice

- Solve exercises in the widget and ask questions in ChatGPT.
- The widget does not duplicate ChatGPT's input composer.
- When you finish, use the "I am done" flow so answers are graded and saved.
- Skipping affects only the current exercise.

## Speaking And Listening

- Listening plays when the environment supports it.
- Some mobile ChatGPT environments do not support speech input. LingoStar shows a centered message, and you can type the answer or skip the current speaking exercise.
- Say "Include speaking next time" or "Turn speaking off" to change future practice sets.

## Track Management

- Ask "Show my language learning tracks" to see your tracks as a table.
- Ask "Delete my Japanese track" to delete a specific track.
- Ask "Delete all language learning tracks" to remove only tracks that belong to the current user.
- Deletion never gives access to another user's tracks.

## Common Commands

- "Start the next practice set"
- "Explain the current exercise"
- "I want to change my settings"
- "Show my language learning tracks"
- "Delete my Japanese track"
