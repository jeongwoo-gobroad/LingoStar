# LingoStar Help

LingoStar helps you keep several language learning sessions and practice them inside ChatGPT.

## Sessions

- Create one session for each target language or goal.
- Use the dashboard to choose a session before starting a section.
- Delete a session from the dashboard only after confirming the action.

## Sections

- A section contains language information, listening, reading, writing, and speaking exercises.
- Finish the current section before asking for the next one.
- Skipping listening or speaking marks only the current exercise as skipped.

## Audio

- Listening uses browser audio when available.
- Speaking can be limited in some mobile ChatGPT environments. If speech input is unavailable, type the answer or skip the current speaking exercise.

## Ask AI

- Ask AI is for questions about the current exercise.
- Your current section and draft answers stay in the widget while ChatGPT answers.

## Settings

- You can adjust per-skill exercise counts, pass threshold, goal section count, speech speed, and speaking availability.
